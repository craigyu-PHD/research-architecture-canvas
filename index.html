Guide

使用說明

1. 貼上研究內容

建議包含研究主題、資料來源、研究架構、研究流程、核心分析、研究輸出與限制。文字不必完全格式化，本地引擎會先整理成初稿。

2. 先出圖，再修圖

按下 AI 解析後會先用瀏覽器內建分析器立即生成。若有設定 Python 或線上 API，系統只會在背景補充建議，不會卡住畫布。

3. 自由編輯模組與線條

點選模組可拖曳、改文字與改類型。開啟「新增線條」後，依序點兩個模組即可建立連接；點線條可修改標籤與樣式。

4. 匯出與發表

完成後可匯出 SVG、PNG 或 JSON。SVG 適合進一步放到 PowerPoint、Illustrator 或 Canva 裡微調。
